# BetterRTP supported server versions

1.8, 1.9, 1.10, 1.11, 1.12, 1.13, 1.14, 1.15, 1.16, 1.17, 1.18, 1.19, 1.20, 1.21, 26.1, 26.2.

Folia support is enabled for 1.21, 26.1 and 26.2.

The modern implementation uses the Folia-compatible entity scheduler and native
`Player#teleportAsync` when available, while retaining legacy compatibility.
